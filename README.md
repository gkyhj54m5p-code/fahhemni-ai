# Fahhemni AI — PDF Study Tools Prototype

A responsive Arabic/English study helper built with HTML, CSS, and vanilla JavaScript. Designed for GitHub Pages.

## Features in this build
- Upload text-based PDF files and extract selectable text in the browser using PDF.js.
- Upload TXT, MD, and CSV files or paste lecture notes.
- Automatic summary from key sentences.
- Practice quiz with interactive answer selection, feedback, and score.
- Smart review flashcards.
- Simplified explanation view and key-points extraction.
- Arabic/English interface toggle and responsive layout.
- No minimum 80-character gate: extracted PDF text is placed directly into the same study input used by all tools.

## Run locally / publish on GitHub Pages
1. Keep `index.html`, `styles.css`, `app.js`, and `README.md` in the same repository folder.
2. Open `index.html` locally, or push the files to GitHub.
3. On GitHub, open **Settings → Pages**, choose the branch and root folder, then save.
4. PDF.js is loaded from cdnjs, so an internet connection is required for PDF parsing.

## Important limitations
This is still a frontend-only prototype. Summary, question creation, explanation, flashcards, and key-point detection use lightweight heuristics in the browser; they are **not generated by a real AI model**. Generated practice questions use sentences from the lecture as answer options, so they are useful for basic practice but not equivalent to high-quality AI-created questions.

- Scanned/image-only PDFs may have no selectable text and need OCR; OCR is not included in this version.
- For real AI explanations, higher-quality question generation, grounded answers, and citations to pages, add a backend/serverless function that calls an AI provider. Keep the API key on the server; never put it in `app.js` or other public frontend files.
- GitHub Pages serves static files only and cannot safely store secret API keys or run a private backend.
- The PDF is parsed in the browser and is not uploaded to this project's server.
