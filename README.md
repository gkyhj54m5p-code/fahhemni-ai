# Fahhemni AI

A responsive bilingual (Arabic/English) study helper built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Features
- Arabic/English interface toggle
- Paste notes or upload TXT, MD, and CSV files
- Simple sentence-based summary
- Practice prompts and review cards
- Responsive layout for mobile and desktop

## Important limitation
This is a front-end student prototype. It does not connect to a real AI model, backend, or database. Summary/questions/cards use simple local text processing in the browser. Do not put API keys in front-end code.

## Publish with GitHub Pages
Upload `index.html`, `styles.css`, and `app.js` to the repository root. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
